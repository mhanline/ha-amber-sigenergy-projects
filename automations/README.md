# Instructions for Automations

## [amber_write_prices_to_csv.yaml](amber_write_prices_to_csv.yaml)

Writes the general and feedin prices to a CSV whenever the price is updated. It can use any sensor, but I use the Amber Express one. If you use a different one, then the `estimate` attribute may need modification.

## [amber_curtailment_trigger.yaml](amber_curtailment_trigger.yaml)

Sets the grid export limit on Sigenergy plant to 0kw during zero or negative feed-in prices, and 20kw when >0.
Amber SmartShift also use this setting to set curtailment. This replicates the Amber Smartshift curtailment feature.
Use the amber_feed_in_price_no_estimates sensor but can use the sensor.your_sensor_name_feed_in_price

## [amber_high_fit_trigger.yaml](amber_high_fit_trigger.yaml)

Notifies when high feed-in occurs in Amber general price.

## [amber_negative_price_notify.yaml](amber_negative_price_notify.yaml)

Notify when negative price occurs. Exempts when demand window is active.

## [amber_write_prices_to_csv.yaml](amber_write_prices_to_csv.yaml)

Writes the general and feedin prices to a CSV whenever the price is updated. It can use any sensor, but I use the Amber Express one. If you use a different one, then the `estimate` attribute may need modification.

## [sigenergy_high_avg_import.yaml](sigenergy_high_avg_import.yaml)

Notify if grid import is happening during a set period.

Uses the demand window from Amber Express as a condition

Uses an average sensor for grid import, to filter out small, spiky imports

## [sigenergy_off_grid_trigger.yaml](sigenergy_off_grid_trigger.yaml)

Notifies you if the Sigenergy system goes off-grid. Ignores unknown/unavailable events.

## [sigenergy_trigger_alarm.yaml](sigenergy_trigger_alarm.yaml)

Notifies if there is an alarm generated by the Sigenergy system. Ignores unknown events (such as when rebooting).
